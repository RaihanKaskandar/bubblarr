Torrent

Add torrent indexers via Jackett or Prowlarr, the same way as in Sonarr and Radarr. Torrents are sent to the torrent client set under Download Clients.

Jackett: add a Torznab indexer and use the "Copy Torznab Feed" URL of the indexer and the Jackett API key.
Prowlarr (manual): add a Torznab indexer with the URL http://prowlarr:9696/{id}/ and the Prowlarr API key.
Prowlarr (automatic sync): in Prowlarr, go to Settings → Apps and add a Mylar application. Use the URL of Bubblarr as the Mylar Server and the API key of Bubblarr (Settings → General) as the API Key. Prowlarr will then add, update and remove its indexers here automatically.
